1. 로비 서버에서 매칭 원하는 클라 매칭 서버에 등록
2. 매칭 서버가 클라들을 선별하고 가상의 방을 생성 후 ID 지급 후 해당 방에 선별된 클라 투입
3. 매칭 서버가 적절한 게임 에이전트한테 보낼 클라들 목록, 방 ID 제공 후 방 생성 요청
4. 게임 에이전트가 요청을 받고 인게임 서버한테 전달
5. 인게임 서버가 방을 열고 게임 에이전트한테 방 열었다고 알림
6. 게임 에이전트가 매칭 서버한테 방 열었다고 알림
7. 매칭 서버가 가상의 방 안의 클라가 속한 로비 서버한테 방이 열린 인게임 서버 주소 전달
	7.1 가상의 방 제거
8. 로비 클라는 세션 레지스트리한테 클라 관리 권한을 해당 인게임 서버로 변경
