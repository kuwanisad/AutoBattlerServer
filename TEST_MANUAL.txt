AutoBattler Server - 로컬 테스트 메뉴얼
================================================================

[ 사전 준비 ]

1. Docker Desktop 실행 확인
2. 컨테이너 실행 (AutoBattleDevTools 폴더에서)

   cd "C:\Users\rlawh\Desktop\Main\AutoBattleDevTools"
   docker-compose up -d

3. BrokerInitializer 실행 - 토픽/큐 초기화
   (이전 테스트 데이터를 완전히 날리고 새로 만든다)

   cd "C:\Users\rlawh\Desktop\Main\AutoBattleDevTools\BrokerInitializer"
   dotnet run

   완료 메시지: "=== 초기화 완료 ==="

----------------------------------------------------------------

[ 서버 실행 순서 ]
(각각 별도 터미널에서 실행한다)

터미널 1 - MasterServer
   cd "C:\Users\rlawh\Desktop\Main\AutoBattlerServer\GameServer\MasterServer"
   dotnet run

   확인: "Now listening on: http://[::]:5100"

터미널 2 - DummySubServer
   cd "C:\Users\rlawh\Desktop\Main\AutoBattlerServer\GameServer\DummySubServer"
   dotnet run

   확인:
   "Kafka 구독 시작: game-events, match-results (GroupId=dummy-sub-server)"
   "RabbitMQ 구독 시작: Queue=reward-queue"

터미널 3 - LobbyServer
   cd "C:\Users\rlawh\Desktop\Main\AutoBattlerServer\GameServer\LobbyServer"
   dotnet run

   확인 (MasterServer 로그):
   "상태 수신: ... (Lobby) 부하 0/100"

----------------------------------------------------------------

[ 메시지 발행 테스트 ]
(터미널 4 - PowerShell에서 실행)

1. Kafka 발행
   Invoke-WebRequest -Method POST "http://localhost:5201/test/kafka?topic=game-events&message=hello-kafka" -UseBasicParsing

2. RabbitMQ work queue 발행
   Invoke-WebRequest -Method POST "http://localhost:5201/test/rabbitmq/queue?queue=reward-queue&message=hello-reward" -UseBasicParsing

3. RabbitMQ fanout 발행
   Invoke-WebRequest -Method POST "http://localhost:5201/test/rabbitmq/fanout?exchange=ops-announcements&message=hello-fanout" -UseBasicParsing

----------------------------------------------------------------

[ 검증 기준 ]

DummySubServer 로그에 아래 두 줄이 찍히면 성공:

   [Kafka] 메시지 수신 - Topic=game-events Partition=[0] Offset=0 Value=hello-kafka
   [RabbitMQ] 메시지 수신 - Queue=reward-queue DeliveryTag=1 Body=hello-reward

※ fanout 메시지(hello-fanout)는 DummySubServer가 reward-queue만 구독하므로
   수신 로그가 안 찍히는 게 정상이다.
   RabbitMQ 관리 콘솔(http://localhost:15672, guest/guest)에서
   lobby-fan, ingame-fan 큐에 메시지가 1개씩 쌓인 걸 확인할 수 있다.

----------------------------------------------------------------

[ 포트 정리 ]

MasterServer   5100 (gRPC), 5101 (REST)
LobbyServer    5200 (gRPC), 5201 (REST/테스트 엔드포인트)
DummySubServer 5300 (REST)
Kafka          9092
RabbitMQ       5672 (AMQP), 15672 (관리 콘솔)
